# Portfolio Alessandro Miniello

Static personal portfolio deployed with GitHub Pages at https://alexx904.github.io/.

## Project Structure

- `index.html`: Italian homepage.
- `en/index.html`: English homepage.
- `css/style.css`: shared styles.
- `js/main.js`: shared interactions and Formspree initialization.
- `assets/`: static media.
- `robots.txt`, `sitemap.xml`, `google480f0cfca81cdb09.html`: SEO and verification files.

## Integrations

- Formspree handles the contact form.
- GoatCounter handles lightweight analytics.

## Deploy

The site is designed to be served directly from the repository root on GitHub Pages.
